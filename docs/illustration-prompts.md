# Retro front-desk illustrations

Created October 27, 2026 with the built-in image generation tool, transparent background mode. Alpha is preserved in the project assets. Original generated files remain in the Codex generated_images directory.

## Selected project assets

- `public/illustrations/front-desk-mascot.png`: smiling ivory CRT computer with yellow screen, navy outlines, cream gloves, magenta sneakers, waving and carrying an envelope. Used above the homepage demo.
- `public/illustrations/front-desk-scene.png`: the same character behind a cobalt desk, catching mail and organizing customer requests, with a plant and toolbox. Replaces the stock tradesperson photo.

## Art direction / reusable prompts

Mascot: Create an original friendly 1990s rubber-hose cartoon computer mascot for a local service-business chatbot. Ivory CRT computer body, bright yellow smiling screen, dark navy outlines, cream gloves, hot-pink sneakers, waving with one hand and holding an envelope. Bold simple silhouette, restrained halftone print texture, cheerful and capable. Transparent background, no lettering, no logos, no photorealism.

Companion scene: Use the supplied mascot image as a character reference. Preserve the ivory CRT body, smiling yellow screen, gloves and pink sneakers. Show the character behind a cobalt-blue front desk catching incoming envelopes and handing over a neat stack of customer requests. Include a small plant and tradesperson toolbox. Friendly retro editorial illustration with bold navy outlines and halftone texture, wide composition, transparent background, no text or logos.

A brighter scene refinement was generated and retained in the generation library; the original companion scene remains selected for the site.

The small vector logo and favicon are editable code assets in `app/components/brand-mark.tsx` and `app/icon.svg`.
